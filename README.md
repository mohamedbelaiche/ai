# نبراس AI — واجهة Chatbot متطورة عبر OpenRouter API

واجهة دردشة ذكاء اصطناعي حديثة، فائقة السرعة، وجمالية التصميم تعتمد على **OpenRouter API** لتمكين الوصول إلى مئات نماذج الذكاء الاصطناعي (مثل Gemma 4 31B, Nemotron 3 Super 120B, DeepSeek V3, GPT-4o, Claude Sonnet 5.5) مع ميزة البث المباشر للإجابات (Streaming SSE) ودعم كامل للغة العربية وتلوين الأكواد البرمجية.

مصممة ليتم رفعها بسهولة على **GitHub** واستضافتها مجاناً بنقرة واحدة على **Vercel**.

---

## ✨ المميزات الرئيسية

- ⚡ **بث مباشر فوري (Real-time SSE Streaming):** كتابة تدريجية للإجابات بدون انتظار انتهاء النموذج.
- 🎨 **تصميم زجاجي عصري (Glassmorphism):** واجهة مستخدم متميزة، متوافقة مع الوضعين الداكن (Dark) والفاتح (Light).
- 🌐 **دعم كامل للغة العربية والإنجليزية:** زر تحويل فوري للاتجاه بين RTL و LTR وخط عربي أنيق (Cairo & Outfit).
- 🆓 **دعم النماذج المجانية والمدفوعة:** اختر مباشرة بين أفضل النماذج المجانية (Gemma 4 31B Free, Nemotron 3 Super 120B Free, Inkling Free) أو أدخل أي نموذج تريده من بين 200+ نموذج.
- 💻 **تلوين الأكواد البرمجية (Syntax Highlighting):** مع زر لنسخ الكود بنقرة واحدة وتحديد لغة البرمجة تلقائياً.
- 🗂️ **حفظ سجل المحادثات محلياً:** تنظيم المحادثات في القائمة الجانبية مع إمكانية التبديل بينها أو مسحها أو تصديرها كملف Markdown.
- 🔒 **حماية وأمان لمفتاح API:** دعم دالتين للعمل:
  1. عبر خادم Vercel Edge Serverless Function (`/api/chat`) مع المتغيرات البيئية `OPENROUTER_API_KEY`.
  2. أو إدخال مفتاح API في الإعدادات ليُحفظ محلياً في متصفحك فقط (`localStorage`).
- 📱 **متجاوب 100%:** تجربة استخدام ممتازة على الهواتف والأجهزة اللوحية وأجهزة الكمبيوتر.


## ☁️ خطوات الاستضافة على Vercel

الاستضافة على Vercel مجانية وتستغرق أقل من دقيقة:

### الطريقة 1: عبر لوحة تحكم موقع Vercel (الأسهل والموصى بها)
1. افتح موقع [Vercel.com](https://vercel.com) وسجل الدخول باستخدام حسابك على GitHub.
2. اضغط على زر **Add New...** ثم اختر **Project**.
3. ستظهر لك قائمة بمستودعاتك على GitHub؛ ابحث عن المستودع `openrouter-ai-chatbot` واضغط **Import**.
4. في شاشة الإعدادات:
   - في قسم **Environment Variables** (المتغيرات البيئية):
     - الاسم (Name): `OPENROUTER_API_KEY`
     - القيمة (Value): الصق مفتاح OpenRouter الخاص بك (يبدأ بـ `sk-or-v1-...`).
     - اضغط على **Add**.
5. اضغط على زر **Deploy**.
6. مبروك! بعد ثوانٍ ستظهر لك شاشة الاحتفال مع رابط موقعك المباشر المنشور عالمياً (مثال: `https://openrouter-ai-chatbot.vercel.app`).

---

### الطريقة 2: عبر موجه الأوامر (Vercel CLI)
```bash
# تثبيت Vercel CLI إن لم يكن مثبتاً لديك
npm i -g vercel

# تسجيل الدخول والنشر
vercel
```

## 🔑 كيفية الحصول على مفتاح OpenRouter API مجاناً

1. ادخل إلى موقع [OpenRouter.ai](https://openrouter.ai).
2. سجل الدخول باستخدام حساب Google أو GitHub.
3. توجه إلى صفحة [Keys](https://openrouter.ai/keys).
4. اضغط على **Create Key**، اكتب اسماً للمفتاح ثم اضغط **Create**.
5. انسخ المفتاح فوراً واحتفظ به.
6. يمكنك استخدام النماذج التي تنتهي بـ `:free` مثل:
   - `google/gemma-4-31b-it:free`
   - `nvidia/nemotron-3-super-120b-a12b:free`
   - `thinkingmachines/inkling:free`
   بدون الحاجة لشحن رصيد إطلاقاً!
